# Dynamic Runtime v0.5

The Network Lab no longer assumes fixed environment values.

Runtime discovery/configuration now covers:

- project root;
- backend/frontend development ports;
- frontend API target;
- modem serial port;
- device/model identity;
- operator/APN values;
- firmware gate state.

## Local settings

Persistent machine-specific settings are stored outside Git in the current user's local application-data directory.

Environment overrides are supported:

```text
T6RA_PROJECT_ROOT
T6RA_PORT
T6RA_MODE
T6RA_BAUD
```

## Serial discovery

The backend enumerates current serial interfaces using operating-system metadata.

Automatic selection prefers generic modem/PCUI/CDC descriptors. It does not depend on a fixed COM number, USB VID/PID, operator name, or APN.

The Settings page can run a read-only discovery probe and explicitly select a port.

## Frontend API

The browser uses relative `/api/...` URLs.

During development, Vite's proxy target is supplied at launch time through a local `.env.local` file generated by the launcher.

## Firmware gates

Firmware status is derived from the actual workspace:

- `firmware/original/`
- `firmware/analysis/verification.json`
- `firmware/recovery/recovery_verified.json`
- `firmware/patches/`

No firmware write is performed by this update.

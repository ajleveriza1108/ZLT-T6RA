# Network Lab v0.4 — Frontend Complete

The primary frontend surfaces are now present and navigable:

- Dashboard
- SIM Info
- Signal Monitor
- Network Scan
- APN / PDP
- Internet Test
- Cell Logger
- Diagnostics
- AT Console
- Firmware
- Settings

The UI supports both deterministic Mock mode and safe Real mode.

The Firmware page intentionally does not offer upload/flash controls yet. It displays recovery gates instead.
